# Calculadora-App

# Justificación del Proyecto}
Elegimos 'Calculadora-App' porque resuelve la necesidad de realizar operaciones matemáticas básicas en una interfaz limpia e intuitiva, permitiendo al usuario efectuar cálculos simples y encadenados sin errores de formato de entrada. Su alcance es adecuado para poner en práctica la metodología de desarrollo y el trabajo colaborativo en un proyecto de corta duración.

# Metodología
Utilizaremos la metodología ágil Kanban debido a que el mini-proyecto cuenta con un conjunto claro de User Stories que pueden ser divididas en tareas independientes e incrementales. Esta metodología nos permite visualizar el flujo de trabajo mediante un tablero con columnas (To do, In progress, Done), responder flexiblemente a los ajustes del código y coordinar la entrega en commits continuos.

# User stories:
- Como usuario, quiero ver una pantalla con los dígitos y operaciones para ingresar cálculos.

- Como usuario, quiero presionar botones numéricos (0-9) para formar números en pantalla.

- Como usuario, quiero realizar operaciones básicas (+, -, *, /).

- Como usuario, quiero presionar '=' para ver el resultado de la operación.

- Como usuario, quiero un botón 'C' o 'AC' para limpiar la pantalla o reiniciar la calculadora.

- Como usuario, quiero evitar la entrada de múltiples puntos decimales en un mismo número.
